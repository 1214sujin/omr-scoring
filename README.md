# omr-scoring
OMR 채점기

'omr_form.pdf'와 같은 형식인 경우에만 채점이 가능합니다.

공식 프로그램이 아니므로 인식 상태가 정확하지 않을 수 있으며, 정확히 채점되었는지는 '{과목명}_답안지스캔_debug' 폴더의 이미지에서 확인하실 수 있습니다.
모든 빈칸이 초록색 상자, 칠해진 칸이 파랑색 상자로 표시된다면 정확하게 인식된 것입니다.

### 사용법

#### 사용 전, python이 설치되어 있는지 확인합니다.

1. 작업표시줄 검색 상자에 'cmd' 또는 '명령 프롬프트'를 검색하여 터미널을 엽니다.
1. 아래 명령어를 입력하여 파이썬 버전이 정상적으로 출력되는지 확인하고, 출력되지 않는다면 python 설치 방법을 검색하여 설치합니다.
   ```
   python -V
   (출력 예시:) Python 3.14.3
   ```

#### python 설치가 확인되면 아래와 같이 실행합니다.
1. 오른쪽 위 초록색 `<> Code` 버튼을 눌러 ZIP 파일로 다운받고, 본 프로그램을 저장하고자 하는 위치에서 압축을 해제합니다.
1. 해당 위치에서 파일탐색기 빈 공간에서 "우클릭-터미널에서 열기" 후 아래 명령어를 입력합니다.
   ```
   python omr_main.py
   ```
   - 주의: 터미널을 끄면 OMR 채점기도 함께 꺼집니다.
1. 반복적으로 사용해야 하는 경우, 배치 파일(파일명.bat)을 만들어 실행하면 편합니다.
   1. 본 프로그램이 압축 해제되어 있는 위치에서 "우클릭-새로 만들기-텍스트 문서"를 선택하여 새 텍스트 파일을 만듭니다.
   1. 텍스트 파일에 아래 내용을 붙여넣습니다.
      ```
      @echo off
      start "" pythonw omr_main.py
      exit
      ```
   1. 텍스트 문서 이름의 확장자를 '.bat'으로 변경합니다.
      - 만약 확장자를 편집할 수 없다면, 파일탐색기 상단에서 "보기-표시-파일 확장명"을 활성화 후 편집합니다.
   1. 이제 해당 파일을 더블클릭하기만 하면 OMR 채점기를 실행할 수 있습니다.
- 채점기에 넣을 파일의 양식은 'omr_form.pdf'와 '샘플' 폴더를 참고하시기 바랍니다.
