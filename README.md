# omr-scoring
OMR 채점기

OMR카드가 'omr_form.pdf'와 같은 형식인 경우에만 채점이 가능합니다.

공식 프로그램이 아니므로 인식 상태가 정확하지 않을 수 있으며, 정확히 채점되었는지는 '결과출력/{과목명}/{과목명}_답안지스캔_debug' 폴더의 이미지에서 확인하실 수 있습니다.
모든 빈칸이 초록색 상자, 마킹한 칸이 파랑색 상자로 표시된다면 정확하게 인식된 것입니다.

## 사용법 (최초 설치 시)

### Python 설치 확인

1. 작업표시줄 검색 상자에 'cmd' 또는 '명령 프롬프트'를 검색하여 터미널을 엽니다.
1. 아래 명령어를 입력하여 파이썬 버전이 정상적으로 출력되는지 확인하고, 출력되지 않는다면 python 설치 방법을 검색하여 설치합니다.
   ```
   python -V
   (출력 예시:) Python 3.14.3
   ```

### OMR 채점기 설치
1. 오른쪽 위 초록색 `<> Code` 버튼을 눌러 ZIP 파일로 다운받고, 본 프로그램을 저장하고자 하는 위치에서 압축을 해제합니다.

### Poppler 설정

1. [이 링크](https://github.com/oschwartz10612/poppler-windows/releases/download/v26.09.0-0/Release-26.09.0-0.zip)를 눌러 poppler를 설치합니다. (링크를 누르면 페이지 이동 없이 다운로드가 시작됩니다.)
1. 설치된 ZIP 파일을 압축 해제하면 `Release-26.09.0-0` 폴더 안에 `poppler-26.09.0`가 있습니다.
1. `poppler-26.09.0`의 폴더명을 `poppler`로 변경하고, OMR 채점기를 압축 해제한 위치로 이동합니다.
   - `poppler` 폴더와 `poppler 설정.bat`이 같은 위치에 있어야 합니다.
1. `poppler 설정.bat`를 실행합니다.
   - '환경 변수(PATH) 설정이 완료되었습니다.' 또는 '이미 환경 변수가 등록되어 있습니다.' 창이 뜨면 OMR 채점기를 정상적으로 사용할 수 있습니다.

## 사용법

1. '샘플' 폴더의 답안, 수강명단 샘플에 맞춰 정답지와 수강생 명단 파일을 준비합니다.
1. 학생 답안지는 검은 마크가 왼쪽으로 가도록 맞춰 스캔합니다.
1. `OMR 채점기.bat`를 실행하여 준비한 파일을 넣고, '채점 시작'을 누릅니다.
1. 채점 결과는 '결과출력' 폴더에서 확인할 수 있습니다. 채점 교과목명에 입력한대로 새 폴더가 생깁니다.
