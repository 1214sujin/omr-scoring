# omr-scoring
OMR 채점기

OMR카드가 'omr_form.pdf'와 같은 형식인 경우에만 채점이 가능합니다.

공식 프로그램이 아니므로 인식 상태가 정확하지 않을 수 있으며, 정확히 채점되었는지는 '결과출력/{과목명}/{과목명}_답안지스캔_debug' 폴더의 이미지에서 확인하실 수 있습니다.
모든 빈칸이 초록색 상자, 칠해진 칸이 파랑색 상자로 표시된다면 정확하게 인식된 것입니다.

### 사용법

#### 사용 전, python이 설치되어 있는지 확인합니다.

1. 작업표시줄 검색 상자에 'cmd' 또는 '명령 프롬프트'를 검색하여 터미널을 엽니다.
1. 아래 명령어를 입력하여 파이썬 버전이 정상적으로 출력되는지 확인하고, 출력되지 않는다면 python 설치 방법을 검색하여 설치합니다.
   ```
   python -V
   (출력 예시:) Python 3.14.3
   ```

#### python 설치가 확인되면 아래와 같이 실행합니다.
1. 오른쪽 위 초록색 `<> Code` 버튼을 눌러 ZIP 파일로 다운받고, 본 프로그램을 저장하고자 하는 위치에서 압축을 해제합니다.
1. `OMR 채점기.bat`을 실행합니다.
   - 채점기에 넣을 파일의 양식은 'omr_form.pdf'와 '샘플' 폴더를 참고하시기 바랍니다.
1. 결과는 '결과출력' 폴더에서 확인할 수 있습니다.
